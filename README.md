# Jogo da Velha em C
Jogo da velha desenvolvido em linguagem C, como projeto prático para exercitar os fundamentos da lógica de programação.

## Desenvolvedor
- Luiz Eduardo Alves Feitosa

## Sobre o projeto
O jogo é executado no terminal e permite que dois jogadores disputem uma partida em um tabuleiro 3x3, alternando suas jogadas até que um deles vença ou ocorra um empate.

## Funcionalidades
-Tabuleiro 3x3 personalizado no terminal;
-Partida entre dois jogadores (X e O);
-Alternância automática entre jogadores;
-Validação das coordenadas informadas;
-Verificação de posições já ocupadas;
-Identificação de vitória por linhas, colunas e diagonais;
-Detecção de empate.

## Tecnologias utilizadas
-Linguagem C
-Biblioteca stdio.h
-Biblioteca stdlib.h

## Conceitos aplicados
-Matrizes bidimensionais;
-Estruturas condicionais (if e else);
-Estruturas de repetição (while e for);
-Funções;
-Manipulação de caracteres;
-Operador ternário;
-Validação de entradas.

## Como executar
1- Clone ou baixe este repositório.
2- Abra o arquivo do projeto em uma IDE ou compilador C.
3- Compile o código.
4- Execute o programa pelo terminal.

## Como executar
Praticar conceitos fundamentais da linguagem C por meio da construção de um jogo interativo, trabalhando principalmente com matrizes, estruturas de controle e validação de dados.
